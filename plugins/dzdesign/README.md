# DZDesign
Codex-only design workflows by DigiZorg. The six skills share the helper `scripts/tools.py`; optional upstream resources are fetched by immutable commit and verified SHA-256 only when requested. No automatic hooks, cloud server, account tokens or other-agent directories are shipped.
See the repository README and `sources.lock.json`. Run `python scripts/tools.py doctor` for local prerequisites. Installing skills does not prove a browser can launch. Python 3.10+, Node 22+ for Taste, and Chrome/Edge for browser checks are needed for the corresponding workflows.
