# DZ Three
Run `python <plugin-root>/scripts/tools.py prepare three`. Read the prepared `SKILL.md` and follow its staged reconstruction workflow, using the generic or character built-in profile as appropriate. No hosted image-to-mesh service or optional plugin is automatically installed.
Run Python tools via `python <plugin-root>/scripts/tools.py run three forge/state.py init --help` and the documented forge/next.py workflow. Relative model, state and reference paths are resolved from the user's project; do not confuse them with plugin paths.
Use the host's image-reading and permitted browser capabilities to compare rendered views with the reference. Describe this accurately as a code-built reconstruction, not photogrammetry or guaranteed exact geometry. Select external API/model integrations only when explicitly requested and approved for any resulting cost or data transfer.
