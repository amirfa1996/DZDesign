# DZ Design Library
Run `python <plugin-root>/scripts/tools.py prepare library`. The returned source includes `design-md/<brand>/DESIGN.md` plus its README. List actual local folders; read only the requested brand or a small relevant shortlist. The pinned release contains 84 design reference files.
Use reference colors, spacing and typography as inspiration, adapting them to the client's content, accessibility and identity. These are third-party analyses, not official brand endorsements. Do not copy logos or assert ownership of another brand. Preserve an existing project DESIGN.md unless the user requests a replacement. Catalog links can lead to external paid services; the local reference collection is what this package makes available.
