# نمونهٔ فروشگاه تی‌شرت برای آزمایش «دیزاین‌یار»

این صفحه یک نمونهٔ مستقل و فارسی برای بررسی توانایی‌های `DZDesign` در Codex است. برند، قیمت، جنس و زمان ارسال ساختگی‌اند. پرداختی انجام نمی‌شود و صفحه برای موتورهای جست‌وجو `noindex` شده است. تصویر محصول نیز گرافیک جایگزین است؛ برای پروژهٔ واقعی از تصویر تأییدشدهٔ صاحب کسب‌وکار استفاده کنید.

## اجرا

1. این پوشه را به‌عنوان پروژه در Codex باز کنید.
2. در ترمینال همین پوشه اجرا کنید:

   ```bash
   python -m http.server 4173
   ```

3. در Codex از مهارت‌ها درخواست بررسی کنید:

   ```text
   $dzdesign این صفحهٔ فروش محصول را با dz-polish از نظر UI/UX، موبایل، دسترس‌پذیری و مسیر افزودن به سبد بررسی کن. اول فقط گزارش ایرادهای اولویت‌بندی‌شده بده؛ هنوز فایل‌ها را تغییر نده.
   ```

4. برای اصلاح بعد از دیدن گزارش:

   ```text
   $dzdesign با dz-polish سه ایراد مهمی را که گفتی در همین نمونه اصلاح کن، صفحه را در اندازهٔ موبایل و دسکتاپ ببین و تغییرات را خلاصه کن.
   ```

5. برای بررسی رفتار مرورگر، پس از نصب وابستگی مرورگر طبق راهنمای `dz-browser`:

   ```text
   $dz-browser http://127.0.0.1:4173 را باز کن؛ اضافه‌کردن بدون رنگ یا سایز، انتخاب رنگ و سایز، تغییر تعداد، افزودن به سبد و چیدمان موبایل را بررسی کن.
   ```

## رفتارهای قابل امتحان

- انتخاب رنگ و سایز و نمایش انتخاب جاری
- اعلام خطا هنگام افزودن بدون انتخاب رنگ و سایز
- افزایش و کاهش تعداد (بین ۱ تا ۹)
- به‌روزرسانی شمارندهٔ سبد نمونه
- چیدمان راست‌چین و واکنش‌گرا و پیمایش با صفحه‌کلید

این نمونه درگاه پرداخت، موجودی واقعی، تحلیل‌گر یا اتصال CMS ندارد.
