# DZDesign
### استودیوی طراحی دیجی‌زورگ برای Codex
طراحی متمایز · اصلاح رابط کاربری · تست مرورگر · مرجع طراحی · عکس به کد سه‌بعدی

**نسخهٔ 0.1.0 — آزمایشی** | [English](README.en.md) | [راهنمای فارسی](docs/GUIDE.fa.md)

</div>

DZDesign یک بستهٔ اختصاصی **Codex** از دیجی‌زورگ است که مسیر طراحی و بررسی را یکجا می‌کند. بسته‌بندی، راهنمای فارسی، انتخاب مسیر و ابزار دریافت منابع توسط دیجی‌زورگ ساخته شده‌اند؛ موتورهای اصلی متعلق به سازندگان معرفی‌شده در [منابع](THIRD_PARTY_NOTICES.md) هستند.

## چه کاری انجام می‌دهد؟

| مهارت | کاربرد | نمونهٔ درخواست |
|---|---|---|
| `dzdesign` | انتخاب مسیر مناسب پروژه | «با DZDesign این صفحه را طراحی و بررسی کن.» |
| `dz-taste` | طراحی صفحه‌ای متناسب با هویت مشتری | «یک لندینگ فارسی با طراحی متمایز بساز.» |
| `dz-polish` | اصلاح تایپوگرافی، فاصله، دسترس‌پذیری و جزئیات | «این فرم را نقد کن و مشکلاتش را اصلاح کن.» |
| `dz-browser` | تعامل و تست سایت با Playwright CLI | «فرم تماس را در موبایل و دسکتاپ آزمایش کن.» |
| `dz-library` | استفاده از ۸۴ مرجع DESIGN.md | «از مرجع Notion الهام بگیر، با هویت برند خودمان.» |
| `dz-three` | بازسازی کدنویسی‌شدهٔ شیء عکس با Three.js | «از این عکس یک مدل سه‌بعدی قابل‌چرخش بساز.» |

## نصب در Codex

در بخش Plugins گزینهٔ **Add plugin marketplace** را انتخاب و `amirfa1996/DZDesign` را وارد کنید؛ سپس DZDesign را نصب کنید. اگر این گزینه در نسخهٔ شما نیست، از CLI به‌روز دارای فرمان plugin استفاده کنید:

```sh
codex plugin marketplace add amirfa1996/DZDesign
codex plugin add dzdesign@digizorg
```

از داخل Codex مهارت را انتخاب کنید یا بنویسید:

```text
$dzdesign پروژه را بررسی کن و برای صفحهٔ اصلی یک جهت طراحی پیشنهاد بده.
```

## پیش‌نیاز و دانلودها

Python 3.10+؛ برای ابزار مرورگر و Taste، Node.js 22+ و Chrome یا Edge. نصب خود پلاگین دانلود یا اجرای خودکار انجام نمی‌دهد. هنگام استفاده، منابع موردنیاز از GitHub با commit ثابت و بررسی SHA-256 در `.dzdesign` پروژه دریافت می‌شوند. Playwright CLI از npm نصب می‌شود. موتور Impeccable جداگانه و با بررسی checksum دریافت می‌شود. این سرویس میزبان یا ابزار درآمدزایی نیست و هیچ API پولی خودکار فعال نمی‌کند.

## وضعیت بررسی

آزمون‌های ساختار بسته، مسیرهای فایل، قفل منابع، استخراج امن، دستورهای راهنما و نصب مستقل اجرا می‌شوند. وضعیت دقیق اجرای محلی در [VALIDATION.md](docs/VALIDATION.md) ثبت شده است. نصب موفق CLI مساوی موفقیت تست مرورگر نیست؛ این محیط قبلاً در بازکردن مرورگر محدودیت داشته است. پشتیبانی همهٔ سیستم‌عامل‌ها و طراحی یک پروژهٔ کامل هنوز تأیید نشده است.

هیچ پوشهٔ `.claude` یا تنظیمات اجرایی آن در بسته وجود ندارد. ثبت مخزن GitHub و نصب از marketplace شخصی، تأیید فهرست رسمی OpenAI محسوب نمی‌شود. راهنمای [انتشار و بازگشت](docs/RELEASE.md) را ببینید.
